KHUSHI PHOTOGRAPHY DEOLA — FREE WEBSITE

FILES
- index.html: complete responsive one-page website.

QUICK TEST
1. Double-click index.html to open it in your browser.
2. Test the WhatsApp button and enquiry form. They open WhatsApp; the form does not store submissions.
3. Internet is needed for the sample gallery photos, which are remote sample images.

IMPORTANT BEFORE PUBLISHING
- Replace sample images with your own photographs, with customer permission.
- Confirm the WhatsApp number is correct.
- No booking backend, database, payment processing, or automatic booking calendar is included.
- The site is free to test locally. Hosting can be free on a static hosting provider, but you will need to create an account and publish the files.

PUBLISH WITH GITHUB PAGES (FREE)
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository named khushi-photography-deola.
3. Upload index.html to the repository root.
4. Open Settings -> Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for the published URL shown in Settings -> Pages.
8. Open the URL on your phone and test all links.
